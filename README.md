# Fresh_Connect

## 📌 Overview
Fresh_Connect is a web application that connects street food vendors with trusted suppliers, making it easier to source fresh ingredients.

## ✨ Features
- Vendor Registration
- Supplier Registration
- Product Listings
- Search Functionality
- User Authentication

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Firestore
- Supabase

## 🚀 Getting Started

1. Clone the repository
2. Open the project
3. Configure Firebase
4. Run the application
